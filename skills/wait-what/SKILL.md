# Wait-What (Circuit Breaker)

หยุดการทำงานปัจจุบันทันที แล้วตอบ 5 บรรทัด ไม่เกินนี้:
1. โจทย์ตั้งต้นคืออะไร (ประโยคเดียว ตามที่ผู้ใช้สั่ง ไม่ใช่ที่เข้าใจเอง)
2. ตอนนี้กำลังทำอะไรอยู่ และห่างจากโจทย์ตรงไหน
3. สมมติฐานที่ยังไม่ได้พิสูจน์ที่พาไปทางนี้
4. ทางเลือกที่ถูกที่สุดถ้าเริ่มใหม่จากจุดนี้ (≤2 ทาง)
5. คำถามเดียวที่ถามผู้ใช้เพื่อฟันธง

ห้ามแก้โค้ด/ไฟล์ใดๆ ในเทิร์นนี้
