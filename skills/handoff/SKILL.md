# Handoff

อ่านคำขอเดิม สถานะปัจจุบัน และผลตรวจที่เกิดขึ้นจริง ใช้ [ฟอร์แมตส่งต่องาน](FORMAT.md) ซึ่ง `continue` ใช้อ่านด้วย

1. ยืนยัน workspace และ repo ปัจจุบัน ถ้ามี Git ให้บันทึก branch, HEAD และไฟล์ที่ยังแก้ค้างด้วยคำสั่งแบบอ่านอย่างเดียว
2. สรุปผลที่ทำแล้วพร้อมไฟล์และผลตรวจ งานค้าง สิ่งที่ลองแล้ว และการกระทำถัดไปที่ทำได้ตรงจุด ตัด secret และข้อมูลเกินความจำเป็นออก
3. ใช้ปลายทางที่ผู้ใช้ระบุหรือช่องทางส่งต่องานที่ workspace กำหนด หากไม่มี ให้ส่งเป็น Markdown พร้อมคัดลอกในแชต เก็บเอกสารแผนและ diff เดิมไว้ หากปลายทางมี handoff ของ workspace อื่น ให้หยุดเขียนและใช้ข้อความพร้อมคัดลอกแทน
