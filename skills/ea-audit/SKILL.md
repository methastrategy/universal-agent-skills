# EA Audit

เมื่อผู้ใช้เรียกชื่อเดิม ให้ใช้ [mql5-ea](../mql5-ea/SKILL.md) เป็น workflow หลัก

- รายงาน `.htm` หรือ `.html` ให้ใช้โหมดอ่านรายงาน offline และตรวจผลห้ามเปิด Tester
- คำขอ Bayesian, TPE หรือ loop ให้ใช้โหมดทดสอบพารามิเตอร์แบบจำกัดงบ เลือกช่วงเวลาและตรวจความพร้อมของ evaluator ก่อน เอกสารใน `mql5-ea` ระบุวิธีสังเกตข้อจำกัดของข้อมูล
- คำขอตรวจระบบ ให้ตรวจไฟล์รายงาน, Python, และเครื่องมือสำหรับโหมดที่ต้องการจาก workspace ปัจจุบัน ถ้าหาสกิลหลักไม่พบ ให้ระบุว่าต้องติดตั้ง `mql5-ea` เพื่อใช้งาน
