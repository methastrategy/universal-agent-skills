# Merea Standard Output Blueprint & Report Template

โครงสร้างแม่แบบรายงานการคิดย้อนรอย (Reverse Engineering Report) สำหรับส่งมอบเมื่อเรียกใช้ `/merea`

---

## Output Template

```markdown
# 🔄 Universal & Technical Reverse Engineering: [Topic / System / Binary]

## 1. สรุปผลการคิดและกลไกการทำงาน (Executive Core & Working Mechanism)
- **สัจธรรมปลายทาง (The Observed Reality)**: สรุปสิ่งที่เกิดขึ้นหรือผลลัพธ์ที่เป็นอยู่ในปัจจุบันใน 1-2 ประโยคชัดเจน (สำหรับ binary: ระบุ architecture, format, signature)
- **กลไกการขับเคลื่อน (How It Actually Works)**: ถอดรหัสฟันเฟืองเบื้องหลัง กลไกที่ทำให้ระบบดำเนินมาถึงจุดนี้ ทำงานอย่างไร ขับเคลื่อนด้วยแรงอะไร

## 2. โครงสร้างองค์ประกอบและกฎพื้นฐาน (Structural Anatomy & Invariants)
- **เสาหลักโครงสร้าง (Core Components / Layers)**: องค์ประกอบสำคัญที่มีอิทธิพลต่อผลลัพธ์ (เช่น ผู้เล่น, ฟังก์ชันหลัก, Call Graph, APIs)
- **กฎที่ไม่มีวันเปลี่ยนแปลง (System Invariants)**: ข้อจำกัดทางตรรกะ กฎธรรมชาติ หรือสิ่งที่ไม่สามารถละเมิดได้ในระบบนี้

## 3. แผนภาพสายโซ่ย้อนกลับ (Visual Reverse Causal Map & Timeline)
```mermaid
flowchart RL
    T0["[ปัจจุบัน T=0]\nผลลัพธ์ที่สังเกตได้ / Shipped Binary"]
    T1["[จุดพลิกผัน T=-1]\nการเปลี่ยนแปลง / Call Dispatch"]
    T2["[สภาวะตั้งต้น T=-2]\nแรงขับเคลื่อน / Underlying Mechanics"]
    Origin["[จุดกำเนิด / Root Cause]\nFirst Principles / Prime Intent"]

    T0 -->|เกิดจากเงื่อนไข| T1
    T1 -->|แตกแขนงจาก| T2
    T2 -->|มีรากเหง้ามาจาก| Origin
```

## 4. การสังเคราะห์และแจกแจงเชิงลึก (Decomposition & Probabilistic Space)
| ลำดับขั้น | เหตุการณ์ / เงื่อนไข | แรงผลักดันเบื้องหลัง | ความน่าจะเป็นของทางเลือกอื่น (Counterfactuals) |
| :--- | :--- | :--- | :--- |
| **Origin (ปฐมบท)** | จุดเริ่มต้นแท้จริง | เหตุผลและปัจจัยรากเหง้า | ทางเลือกที่ไม่ได้ถูกเลือก |
| **Inflection (จุดผกผัน)** | จังหวะที่ระบบเปลี่ยนทิศ | แรงกระตุ้นภายนอก/การตัดสินใจ | ทางเลือกที่เกือบเกิดขึ้น |
| **Convergence (สู่ปัจจุบัน)**| สภาพที่บีบให้เกิดผลลัพธ์ | Feedback Loop ที่ล็อกสถานะ | ความผันแปรที่เหลืออยู่ |

- **การประเมินความน่าจะเป็น (Bayesian Probability Assessment)**: วิเคราะห์ว่าผลลัพธ์ปัจจุบันเกิดขึ้นจากความบังเอิญ หรือเป็นผลลัพธ์ที่หลีกเลี่ยงไม่ได้ (Deterministic Convergence) ตามเงื่อนไขที่มี

## 5. บทสรุปชี้ชัด "สิ่งที่ควรจะเป็น" และทิศทาง (The "Should Be" Verdict & Trajectory)
- **สิ่งที่ควรจะเป็นตามหลักเหตุและผล (The Normative Ideal)**: หากตัดสิ่งรบกวน อคติ หรือข้อบกพร่องออกไป สภาวะที่ถูกต้อง สมบูรณ์ และควรจะเป็นคืออะไร
- **จุดปรับแก้เพื่อเปลี่ยนผลลัพธ์ (Actionable Leverage Point)**: หากต้องการเปลี่ยนปลายทาง หรือ Recreate ฟังก์ชันนี้ในระบบเรา ต้องต่อยอดอย่างไร

## 6. สรุปภาพรวมภาษาไทย (Thai Executive Wrap-Up)
- สรุปบทวิเคราะห์แบบกระชับ ตรงประเด็น เห็นภาพที่มาที่ไป ชี้ชัดจุดกำเนิด และคำแนะนำสำหรับก้าวต่อไป
```
